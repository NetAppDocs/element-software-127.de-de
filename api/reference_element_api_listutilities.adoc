= ListenUtilities
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Methode verwenden `ListUtilities`, um die Vorgänge aufzulisten, die für die Ausführung auf einem Node verfügbar sind.



[[parameters]]
== Parameter

Diese Methode hat keine Eingabeparameter.



[[return-value]]
== Rückgabewert

Diese Methode hat den folgenden Rückgabewert:

|===
| Name | Beschreibung | Typ 


 a| 
Versorgungsunternehmen
 a| 
Liste der derzeit auf dem Knoten verfügbaren Dienstprogramme.
 a| 
String-Array

|===


[[request-example]]
== Anforderungsbeispiel

Anforderungen für diese Methode sind ähnlich wie das folgende Beispiel:

[listing]
----
{
   "method": "ListUtilities",
   "params": {},
   "id" : 1
}
----


[[response-example]]
== Antwortbeispiel

Diese Methode gibt eine Antwort zurück, die dem folgenden Beispiel ähnelt:

[listing]
----
{
  "id": 1,
  "result": {
    "utilities": [
      "ResetDrives",
      "ResetNode",
      "RestartNetworking",
      "RestartServices",
      "CreateSupportBundle",
      "DeleteAllSupportBundles",
      "CreateClusterSupportBundle"
    ]
  }
}
----
